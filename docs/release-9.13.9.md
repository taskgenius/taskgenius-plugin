# Task Genius 9.13.9

汇总旧布局维护分支自 9.13.2 以来的习惯集成、项目管理、积分与奖励、任务视图和编辑修复。保留原设置导航与风格。发布源为 PR #3 合并后的 legacy/9.13.1，默认 master 分支不作切换。

## 功能与修复

- 集成 JamesCliffordSpratt/obsidian-habits 的 Markdown 习惯功能，保留 MIT 许可。支持每个习惯一个 MD、可配置路径、旧记录兼容、目标和上限、间隔与周期、补打卡、重新安排和忽略漏打卡。卡片列数可选，完成状态与图标更清晰。
- 内置积分与奖励页面，保留原每日打卡与积分数据接入。每日完成任务计分；历史支持日期筛选、对应次数统计、左右对齐与零积分记录隐藏。
- 项目使用项目笔记管理，支持归档、删除、颜色、手动排序、父文件夹及项目甘特图。向项目归入任务时移动到项目笔记，避免重复项目标签；移动项目时间不会改变成员任务的截止日期。
- 修复初次打开空白、列表与树切换、视图设置同步、搜索与筛选结果刷新、矩阵旧结果残留。预设筛选跟随工作区和视图；矩阵与看板拖动更新任务属性，表格列宽保存。
- 普通 Markdown 页面与 Task Genius 共用任务状态和完成日期同步；暂停图标统一。
- 编辑与新建任务复用同一表单。日期与时间同排，可只填日期，可清除时间。积分、标签与可搜索任务依赖位于更多属性。
- 日历网格操作用于任务，点击顶部日期标题打开对应日记、周记、月记或年记；移除冲突的额外周期笔记按钮。修复时间事件定位、当前时间线、排期布局与周数显示。
- 精简无效或冗余设置，移除右侧栏和全局筛选配置，完善中英文翻译与可复现的日历依赖补丁构建。

完整修改过程保留在 PR 的逐次提交，以及 docs/native-checkin-9.13.3.md、docs/fixes-9.13.4.md 至 docs/fixes-9.13.9.md、docs/habits-integration.md 和审计记录中。

## 安装

BRAT 仓库：Platinum1154/taskgenius-plugin，版本：9.13.9。

手动安装：保存正在编辑的内容，下载 main.js、styles.css、manifest.json 放入现有插件目录后，手动关闭并开启 Task Genius 一次。也可下载 task-genius-9.13.9.zip。请保留原 data.json 和习惯、每日打卡、积分 Markdown 文件。
