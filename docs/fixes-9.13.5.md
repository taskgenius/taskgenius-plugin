# Task Genius 9.13.5

- 标题栏统一使用原生大小、间距和悬停样式；移除 Default Cycle 选择和单独的预设下拉框。预设仍可通过筛选图标菜单选择、编辑和清除。
- 积分与奖励合回同一页。加分项与奖励兑换并列显示，积分流水、积分规则仍在同一页面中切换。
- 原生卡片／仪表盘布局改在 **设置 → 习惯 → 布局 → 习惯页面布局** 中选择，不再在习惯页面显示布局下拉框。
- 原生卡片使用 Habits 的目标、限额、计划、暂停、跳过、失败和补打卡规则。显示目标与单位、周期总量和每日目标；未完成在前，已完成在后。
- 热力图按四种状态显示：未记录、已记录未达标、达标、达到两倍目标。限额型习惯另外标出超限，超过限额不会被当作超额完成。
- 表格状态列至少保留完整状态文字所需的宽度，整表不再挤压状态列。列较多时可横向滚动。
- 搜索会展开包含匹配任务的已折叠分组；被筛掉的父任务不再隐藏匹配子任务。缺少 children 信息、自引用或循环父子关系不会导致结果为空。
- 事件视图排除项目笔记本身，保留项目内有日期的复选框任务。项目甘特图只修改项目日期；项目日期不再作为内部任务的默认日期，任务明确设置的截止日期保留。
- 任务详情移除操作类型／完成后操作编辑和英文标签提示。依赖选择只列出任务，不列出整页任务或项目行，按任务名称搜索。
- 修复矩阵筛选为空时旧卡片残留、追加空状态以及旧分批渲染覆盖新结果的问题。
- 所有侧边栏视图，包括系统视图，均可通过右键“在侧边栏隐藏”。恢复显示可在设置的视图列表中操作。
