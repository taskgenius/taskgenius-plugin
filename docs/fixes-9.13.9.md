# Task Genius 9.13.9 试用说明

## 本次修改

1. 日历网格保留创建任务操作，打开周期笔记改为点击顶部日期标题。月视图标题打开月记，周视图标题打开周记，日视图标题打开日记，年视图标题打开年记。移除单独的四个笔记按钮，避免同一次点击既打开日记又弹出新任务窗口。
2. 新建与编辑任务窗口加宽，日期和时间同排显示，日期标签保持完整；窄窗口可以滚动。
3. 编辑任务直接继承新建任务表单，复用同一编辑器、预览、字段及布局。保存按钮仍用于更新原任务，保留原任务 ID 和未修改的信息。积分、标签、依赖位于双方共用的“更多属性”中；取消编辑不保存任务，也不改新建任务的模式偏好。
4. 暂停状态统一使用暂停图标。即使关闭可选的 Task Genius 自定义任务图标，暂停图标仍会显示；原图标开关不被改动。
5. 时间栏旁增加“× 清除时间”。清除后保留日期，保存和重新索引后仍为纯日期；正文的自然语言日期不会把手动清除的时间再填回来。清空表单也会同步清空可见的日期与时间控件。
6. 顶部显示完整筛选名称，窄窗口不遮挡视图按钮。
7. “忽略所有过去漏打卡的习惯”移入设置 → 习惯 → 常规，保留已有记录和积分。
8. 积分明细筛选今天、最近 7 天、最近 30 天时，打卡记录数与积分使用相同时间范围。
9. 选择项目后以项目笔记作为任务写入位置，任务预览和保存内容不再重复加入项目标签或行内项目字段。

## 加载新版

保存正在编辑的内容后，手动关闭并重新开启 Task Genius 一次即可。安装只替换 main.js、styles.css、manifest.json，并备份旧程序和现存原始记录；设置及记录文件保持不变。
