# Task Genius 9.13.4 修复说明

## 项目

在侧边栏右键项目，选择“删除项目”，或打开“编辑项目信息”，使用底部的删除按钮。删除会先确认，再将项目笔记和其中的任务移入 Obsidian 回收站。归档项目管理页也有删除入口。

项目中的“新增任务”使用统一的新建任务窗口，预选当前项目，并将任务写入项目笔记。项目内新增任务不会因为上一次使用“整页任务”而改为创建另一篇任务笔记。

## 习惯

习惯页默认使用原生卡片布局。使用布局下拉框切换到“仪表盘布局”，两种布局读取同一批习惯笔记。外层容器不再显示独立边框；移除文字按钮“创建习惯”，通过加号新增。

卡片展示近三十天记录。点击历史日期方格选中日期，再使用右侧按钮补打卡；计数习惯使用加减按钮。更多操作中可编辑、暂停、删除习惯，以及处理当天的打卡状态。

## 普通笔记中的任务

正常勾选任务完成时，自动写入 `✅ YYYY-MM-DD` 或当前设置的行内完成日期；已有完成日期保留，取消完成时移除完成日期。阅读模式的复选框修改也纳入同步。

启动、打开笔记、导入已完成的旧任务不会批量补写今天的日期。代码块中的示例复选框不会被改写。无法区分的同名重复任务采用保守处理，不猜测其历史完成时间。

## 预设筛选

标题栏中可直接选择“待办”“已完成”“已放弃”“本月任务”，以及自己保存的预设。预设筛选作用于当前页面范围；例如项目页仍保留当前项目范围。

在旁边的筛选菜单或设置的“预设筛选”中新增、编辑规则。状态、优先级、日期范围、项目和已有标签主要使用下拉选项。指定日期使用日期选择器；只有文字和路径条件需要输入文本。高级查询为可选项。

已移除标题栏中原来的“匹配全部过滤器组／添加过滤器组”入口。修复已完成任务在应用预设前被移除的问题，以及内容列表重复过滤、标签精确匹配、没有日期、带引号项目名称等问题。

## 标题栏与页面

搜索、预设、列表／树／看板／日历切换、所有周期、通知和设置统一放在 Obsidian 原有标题栏。较窄的窗口会自动换行。习惯、积分和奖励也使用标题栏搜索。

积分与奖励为两个独立页面。积分页包含加分项、流水和积分规则；奖励页用于管理愿望和兑换奖励，两者共用余额。

修复页面切换时积分页未隐藏的问题，以及重复更新表格和隐藏期间尺寸未刷新导致的空白问题。表格重新分配默认列宽；之后仍可拖动调整并保存。

## 项目甘特图、矩阵和依赖

“Project plans”改为“项目甘特图”。拖动项目条移动起止日期；拖动两端手柄调整开始或结束日期，写回项目笔记属性。拖动空白区域平移图表；使用放大、缩小、今天按钮，或 Ctrl 加滚轮缩放。

矩阵卡片的状态与任务文字放在同一行。任务依赖改为按名称搜索选择，自动生成稳定标识并阻止循环依赖。移除手工填写任务 ID 和重复规则的编辑入口，已有笔记内容保留。

## 设置与验证

保留原设置导航和行式布局。清理旧项目标记前缀、上下文前缀、索引技术开关、自定义日期兼容入口等；保留需要用户选择的设置，改用具体说明。

测试包含真实筛选流程、状态日期写入、项目删除、依赖选择、连续列表树切换、原生习惯卡片打卡，以及 SVG 甘特图拖动。界面自动测试使用独立测试环境，不接管用户鼠标键盘。

安装只替换插件代码文件，保留 Markdown 和插件配置，并在安装前备份。需要手动关闭、开启一次 Task Genius 才能加载新版本；不会自动重启 Obsidian。
