# Task Genius 9.13.6

本次对应七项反馈，保留原设置样式与原 Markdown 记录。

1. 顶栏：通知、设置、视图快捷操作和 Obsidian 原生操作共用右侧操作区。去除左右按钮组各自的底边与阴影，重绘时不会重复生成操作区。Default Cycle 不再出现。
2. 习惯：原生卡片和紧凑列表使用两列，窄窗口自动一列。原生卡片显示所选日期、目标／限额、每日目标和周期进度；左右切换查看对应日期，日期按钮返回今天，日期输入可选任意一天。已完成习惯淡化并排列在未完成之后；限额型超限仍按失败显示，原记录和补打卡规则保留。
3. 表格：拖动列宽后，在松开时保存到当前表格视图，重开恢复；不同自定义表格分别保存，状态列保留可读宽度。
4. 拖动：矩阵和看板只拖动任务卡片，按钮和链接仍正常操作。看板按分组修改状态／优先级／标签／日期／项目等属性；标记完成同时写完成日期。矩阵拖动保存紧急／重要标签和显式象限标记 `#quadrant/象限ID`，避免截止日期推断把任务又送回原象限，不修改任务截止日期。写入失败恢复原状态。
5. 积分与奖励：保留同一页面，移除“习惯／打卡记录”汇总卡。已完成且有完成日期的 Markdown 复选框任务计入相应日期，默认沿用“完成任务”打卡的每项积分（没有该规则时每项 1 分），任务自带积分优先。自动积分仅补足实际任务积分与当天既有任务打卡、任务奖励流水之间的差额；不改原打卡记录，不重复计分。不补造缺失的完成日期，项目计划和整页任务不计入。
6. 布局：设置 → 习惯 → 布局只保留一个“习惯页面布局”选项，包含原生卡片、紧凑列表、网格、轮播、垂直滚动；保留原来选中的布局。
7. 侧边栏：系统视图与自定义视图均可在上方、下方互相拖动并保存顺序，空区域也可接收。下方不再只展示前五项，也不再把其余视图藏进省略菜单；列表滚动展示。主动折叠侧栏后的图标栏同样完整显示并支持滚动。

安装只替换 main.js、styles.css、manifest.json；安装前备份插件、配置与习惯／积分源文件，不主动重启 Obsidian。已经打开的实例需要手动关闭再启用一次 Task Genius 才能加载新代码。

验证：界面回归 41 项通过，习惯回归 59 项通过；11 个相关 Jest 测试套件共 61 项通过。完整 Jest 测试共 1550 项，1401 项通过、149 项失败；其中 146 项与前版既有失败相同，另 3 项为跨午夜日期模拟问题，已在未修改的 9.13.5 副本中复现。未发现新增失败，完整历史测试集仍未全部通过。上述验证不代替用户在实际 Obsidian 窗口中的外观验收。
