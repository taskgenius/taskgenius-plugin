# Task Genius 习惯功能使用指南

## 开始使用

1. 打开 Task Genius 设置 → **习惯**，开启习惯功能。主设置的导航和旧布局保持不变。
2. 在习惯设置的**常规**中指定**习惯文件夹**。每个习惯保存为一个 Markdown 文件。已有 Habits 文件可直接读取。
3. 打开 Task Genius 的习惯页，点击**创建习惯**。也可以用命令面板中的 Task Genius: Habits 命令创建习惯、打开侧栏，或插入看板、统计、表格、热力图。

修改文件夹只切换读取位置，不会自动搬动旧文件。要搬家，请在 Obsidian 文件列表中移动习惯文件，再修改设置中的目录。

## 选择习惯类型和排期

| 需求 | 选择方式 |
| --- | --- |
| 每天阅读，做了就打卡 | 二元习惯 + 每天 |
| 每天喝水 2 升，每次增加 0.25 升 | 计数习惯，目标 2，步长 0.25，单位 L |
| 学习或运动累计多少分钟 | 计时习惯，目标使用分钟 |
| 每周任意三天健身 | 每周灵活目标，目标 3 次 |
| 每月累计一定数量 | 每月灵活目标 |
| 周一、周三、周五固定执行 | 每周，选择多个星期 |
| 隔一天健身，补做后继续隔一天 | 每隔 N 天，N=2，排期选择**从实际完成日期计算** |
| 戒除某事、控制摄入上限 | 上限目标；二元上限表示当天一次也不做 |
| 通过写笔记或完成笔记内清单打卡 | 在实验功能开启笔记习惯，再创建笔记类型 |

固定间隔沿用开始日期。按实际完成日期间隔时，漏做会一直保留待办；例如 1 日完成、3 日漏做、4 日补做，下一次是 6 日。上限目标使用固定排期。

## 日常操作

切换日期可以补记历史数据。勾选或增加次数后，数值会写进对应习惯文件的记录属性；撤销打卡也会更新文件。计数支持小数。

右键或长按习惯可以编辑、打开原文件、暂停、跳过、标为失败、稍后提醒，或停止追踪。**停止追踪**保留历史；恢复后继续记录。删除操作有确认框。

评论可写标签和笔记链接，保存在习惯 Markdown 正文的日志区中。请保留日志区域的开始、结束标记。

布局可选轮播、网格、纵向或紧凑列表，并可设置分组、颜色、图标及排序。侧栏适合快速打卡；详情和统计页适合查看历史、趋势、连续记录和不同习惯的对比。统计页也可导出 PDF。

## 旧记录与原有 Habits 插件

已有 Habits 的习惯文件不需要转换。首次接入会读取它的目录、字段名称等兼容设置，不会复制 API 密钥，也不会自动开启对外写入。

原 Task Genius 的日记属性记录仍在**原有 Task Genius 习惯**中可用。点击**导入原有记录**，确认数量和目录后可转成独立习惯文件。原始数据不修改，完整来源快照也会写入新笔记；重复导入会跳过已导入项目。计划型旧习惯按事件拆分，映射型按数值导入，原选项定义保存在来源快照中。

导入是一次快照，之后请选择新习惯或旧日记属性中的一种方式继续记录，避免两套记录分叉。

独立 Habits 仍开启时，自动提醒和笔记同步由它负责。准备完全改用 Task Genius 时，关闭独立 Habits，再重新加载 Task Genius 一次，使旧笔记中的代码块也交给 Task Genius；无需重启 Obsidian。新插入的代码块使用 `tg-` 前缀，可在两者并存时使用。

## 可选集成

- **Reminder**：在常规设置启用，选择每日笔记或固定提醒文件，并给习惯设置时间。提醒清单的勾选和习惯记录双向同步。需要自行安装并启用 Reminder 才能获得其通知功能。
- **笔记习惯 / Templater**：在实验功能开启。可按字数、清单全部完成、清单完成指定数量，或组合条件判定。模板使用 Templater 语法时需启用 Templater。
- **漏做改期**：在实验功能开启，再通过漏做列表选择新的执行日期。
- **AI 总结**：在实验功能开启，填写自己的兼容接口、模型和密钥。只有点击生成总结时才向所配置服务发送统计内容；这不是打卡必需功能。

文件变化应直接反映到习惯页。手动编辑时请保持 YAML 格式正确，并确保文件位于当前配置的目录；更改字段名称请使用高级设置中的“应用属性名修改”，让已有记录一起更新。
