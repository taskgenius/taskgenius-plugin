# Task Genius 9.13.8 试用说明

第 4 项“空格/双击项目弹窗”已按要求取消。

## 项目

- 项目可以拖动到另一项目上方或下方排序；侧边栏排序菜单可以选择“手动排序”。顺序记录在项目笔记的 `projectOrder` 属性中。
- 右键项目 → 编辑项目详情，可选择项目颜色、父级文件夹，也可以填写新的父级文件夹名称。
- 父级文件夹使用项目目录里的实际文件夹。移动项目时使用 Obsidian 文件管理接口；项目名及任务内容保留，侧边栏和项目页按文件夹展开。
- 新建项目也可以选择父级文件夹及颜色。颜色记录在项目笔记的 `projectColor` 属性中。
- 创建任务时选择项目，写入位置立即显示对应项目文件；任务保存到该项目笔记。
- 甘特图拖动项目或两侧边缘时显示日期范围。修改项目时间不会移动项目内任务的截止日期。

## 日历和排期

- 日历顶部提供日记、周记、月记、年记入口。沿用已有 Periodic Notes、Calendar、Daily Notes 的文件夹、命名及模板；已有笔记直接打开，不覆盖内容。
- 月历日期数字和周/日视图日期标题可以打开对应日记。顶部周期标题打开当前周期笔记。
- 周数按日历年计算：1 月 1 日所在周为第 1 周，跨年重新计数，周起始日遵循日历设置。甘特图和习惯界面也显示周数。既有周记的文件命名格式保留。
- 修复重叠事件错位，任务在独立列中显示；显示工作时段时，任务位置、点击和拖动的时间使用相同计算。
- 日视图和周视图当天显示红色当前时间线，每分钟更新，不中断拖动。
- 排期左侧未安排任务列表独立滚动，日期网格紧跟星期标题。拖入某天只修改计划日期，保留截止日期及已有时间。

## 任务窗口和筛选

- 编辑任务采用创建任务的左右布局和同一套 Markdown 编辑器，保留暂存、取消及保存行为。
- 日期栏提供日期及时间选择器，时间留空即保存纯日期；选择 00:00 会保留明确的午夜时间。日记写入日期也可以直接选择。
- 暂停状态统一使用暂停图标。
- 每个侧边栏视图独立保存筛选预设和临时规则，顶部显示当前筛选名称。切换视图会恢复该视图的筛选。
- 右上角“重置过滤器”用于清除当前页面临时筛选、预设及项目选择；它不是重建任务索引。其他窗口的筛选事件不再串入当前页面。
- 已删除设置中的旧全局筛选配置、对应类型和执行逻辑。旧设置中残留的全局规则不再参与任务过滤。

## 习惯、积分与奖励

- 设置 → 习惯 → “忽略所有过去漏打卡的习惯”：一次忽略今天之前的漏打卡提醒。它只记录提醒截止点，保留全部习惯记录、周期和积分；未来漏打卡仍会正常提醒。
- 积分与奖励保持同一页面并使用全宽。积分明细左侧为积分记录，右侧为习惯积分；数字统一右对齐。
- 积分明细可以筛选最近 7 天和最近 30 天，范围包含今天。零积分习惯不显示。
- 习惯积分按每日贡献汇总筛选，保留每周/每月额度规则，不会因筛选范围截断而重新计算错额度。
