2. 设置：删除“时间解析”设置入口，索引和捕获使用统一内置解析规则；移除错过习惯通知的实验开关，功能直接启用。保留其他设置原来的分类和视觉样式，不删除用户已有设置数据。
3. 详情：统一为与新建任务相近的居中悬浮编辑窗，保存才落盘，取消不写文件。
4. 身份与空值：详情编辑不再重写任务 ID 或把行号减一；打开时先刷新对应文件再查最新任务，无法唯一定位的旧任务会明确提示，不把 undefined 当任务内容写回。
5. 暂停：原先显示 No status 的旧暂停组显示为“暂停”，使用暂停图标；不批量改变原状态符号。
6. 日期时间：新建和详情都可填 `2026-11-12` 或 `2026-11-12 09:30`，自动识别是否包含时间，无需额外开关。支持明确的 `00:00`，无效日期不能保存；编辑其他字段会保留已有时间。
7. 任务排期：侧边栏新增“任务排期”，可将未安排任务拖入日历，或在日期间拖动；写入计划日期，保留截止日期及已有具体时刻。拖回未安排区域可清除计划日期。
8. 项目甘特图：只保留“今天、周、月、年”。周显示上周／本周／下周，月显示上月／本月／下月，年显示去年／今年／明年；移除内置过滤器与缩放按钮，保留原来项目日期拖动和甘特图滚动操作。
9. 右栏：移除 Task Genius 的右侧详情栏、按钮、注册与相关实现；旧详情窗格会在布局就绪时关闭。任务详情改用浮窗。
10. 刷新：修复带任务 ID 的写入完成事件被跳过、而普通写入又未发送单任务更新的通知缺口。保存后直接读取源文件重新索引；同文件解析按顺序执行，异步查询检查索引版本并重读，避免旧结果覆盖新结果；数据未变化但列表被清空时也会恢复绘制。
11. 习惯外观：去掉第二个可见日期和热力图说明文字。设置 → 习惯 → 常规 → 习惯列数可选自适应或一至四列，默认自适应可用宽度。显示习惯／分组图标，已完成项更暗，加号靠右。使用独立关闭控件处理右上角叉号，不依赖主题中的原生按钮结构。
